WHAT THIS ARCHIVE IS
--------------------
The COMPLETE source tree of Agentic-Bug-Hunter with the RhodawkAI Edition
integration applied — every file from upstream is included, not a patch or a
delta. 454 of the 461 files in this archive are byte-identical to upstream
agentic-bug-hunter at the pinned commit; the remaining 23 are listed below.

Base project:  awarexone/agentic-bug-hunter
Base commit:   82f4512ec432765297c36e6b3ef7dc3fe5a58be2  (upstream 6.0.1)
Fork edition:  agentic-bug-hunter-rhodawkai-edition 6.1.0

Integration tested against (cloned separately by ./install.sh into RTW_HOME,
default ~/Tools/reconftw — NOT included in this archive):
  six2dez/reconftw @ 39252113a854bdac0b785f144b9fae1fa8ca35fc

The one functional addition: wherever ABH's own recon pipeline hits a
capability it doesn't have, it delegates to reconFTW's equivalent function —
deterministically (capability_registry.py + rtw_adapter.py), in all four
runtimes (CLI engine, ReAct agent, interactive harness, MCP server), fail-closed
on scope, with modules/vulns.sh never delegated. See the "RhodawkAI Edition"
lead section of README.md and CHANGELOG.md for the full capability map.

QUICK START
-----------
  unzip agentic-bug-hunter-rhodawkai-edition-6.1.0.zip
  cd agentic-bug-hunter-rhodawkai-edition-6.1.0
  ./install.sh                        # installs ABH + clones reconFTW pinned
  bash install_tools.sh               # ABH-native tools
  bash install_tools.sh --rtw-deps    # the 7 gap-fill capabilities' binaries only
  python3 bughunter/tools/capability_registry.py --banner

  # Recon with gap-fill (scope patterns are forwarded to the adapter):
  bughunter recon target.com --scope-domain "*.target.com"

  # Without RTW_HOME set, everything behaves exactly as upstream ABH.
